# Travel Management System - Frontend (Angular) 🌐

This repository contains the **frontend Angular application** for the Travel Management System.  
It provides an interactive UI for managing **bookings, vehicles, agents, and drivers** with **role-based routing**.


## ✨ Features
- Role-based Login (Admin & Employee)
- Reusable Angular Components (Booking Forms, Vehicle Cards, Dashboards)
- Dynamic Agent Dashboard with Payment Allocation
- Real-time Revenue Statistics with Graphical Charts
- Form Validation and Error Handling
- REST API Integration with ASP.NET Core Backend

## 🛠️ Tech Stack
- **Frontend:** Angular 18, TypeScript
- **UI Framework:** Bootstrap,Angular Material
- **State Management & Async:** RxJS
- **Backend API:** ASP.NET Core Web API
